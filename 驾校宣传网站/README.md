# 🚗 驾校宣传网站

移动端优先的驾校宣传单页网站，用户扫描二维码即可访问。

## 📁 文件结构

```
驾校宣传网站/
├── index.html          ← 网站全部代码（唯一核心文件）
├── images/             ← 图片素材文件夹
│   ├── README.txt      ← 图片替换说明
│   ├── logo.png        ← 驾校 Logo（替换）
│   ├── grounds/        ← 训练场地照片（替换）
│   └── coaches/        ← 教练照片（替换，可选）
├── qrcode.png          ← 网站二维码图片（部署后生成）
└── README.md           ← 本文件
```

## 🚀 如何部署（免费）

### 方法一：GitHub Pages（推荐，免费）

1. 注册一个 [GitHub](https://github.com) 账号
2. 创建一个新的仓库（Repository），名称随意，比如 `jiashu`
3. 将本文件夹所有内容上传到该仓库
4. 进入仓库 → Settings → Pages → Source 选择 `main` 分支 → Save
5. 等待 1-2 分钟，页面地址会显示为：`https://你的用户名.github.io/jiashu`
6. 用这个地址生成二维码即可

### 方法二：直接发给别人

把 `index.html` 文件直接发送给别人，在手机浏览器中打开即可预览效果。

## 🔧 如何替换内容

所有需要替换的地方都用 **【中括号】** 标出，对照以下清单逐一替换：

| 替换项 | 搜索关键词 | 替换为 |
|--------|-----------|--------|
| 驾校名称 | 【驾校名称】 | 你的真实驾校名 |
| 电话 | 【请填写电话】 | 真实联系电话 |
| 微信号 | 【请填写微信号】 | 真实微信号 |
| 公众号 | 【请填写公众号】 | 真实公众号名称 |
| 详细地址 | 【请填写详细地址】 | 真实地址 |
| 课程价格 | ¥XXXX | 实际课程价格 |
| 学员姓名 | 【学员姓名】 | 真实学员姓名 |

## 🖼️ 如何替换图片

1. 找到页面中的占位框（显示"🖼️ 图片位置"的地方）
2. 准备你的真实照片，放入 `images/` 文件夹
3. 在 `index.html` 中搜索 `img-placeholder`，找到对应位置
4. 将占位框替换为 `<img src="images/你的照片.jpg" alt="描述">`
5. 同理，视频占位框需要替换为腾讯视频/视频号等的嵌入代码

## 📱 如何生成二维码

部署到 GitHub Pages 获得网址后：
- 方案一：Chrome 浏览器打开网站 → 地址栏右侧点分享 → "创建二维码"
- 方案二：访问 [QR Code Monkey](https://www.qrcode-monkey.com) 免费在线生成
- 方案三：使用草料二维码（cli.im）生成，支持添加 Logo

## ⚠️ 注意事项

- 表单提交目前是模拟的，如需真实提交功能，可接入 [Formspree](https://formspree.io)（免费额度够用）
- 地图导航链接目前指向通用地图，建议替换为高德/百度地图的具体位置链接
- 微信长按识别二维码功能在部分浏览器中可能不生效，建议同时附上微信号文字
